Deployable Scripted Input Agent
Multi-Platform Command-Line Agents

Deploy standalone data onboarding agents onto Windows, Linux, or macOS endpoints. Agents run scheduled scripts, monitor logs, and ship telemetry directly to CyberGlass.

🐧 Linux / macOS (cURL & Bash)
🪟 Windows (PowerShell & CMD)
🐍 Python Agent Script
⚡ Compiled Native Executable
# Linux / Bash 1-Line Deploy & Run: 
curl -s http://localhost:9401/api/v1/agent/script | python3 - --server http://localhost:9401 --script "netstat -tuln" --interval 30 --source linux_netstat --index main
Runs zero-dependency agent as a daemon or cron task. For background execution: nohup curl -s http://localhost:9401/api/v1/agent/script | python3 - ... > /tmp/cg.log 2>&1 &
# Windows PowerShell 1-Line Deploy & Run: 
Invoke-WebRequest -Uri "http://localhost:9401/api/v1/agent/script" -OutFile "$env:TEMP\cg-agent.py"; python "$env:TEMP\cg-agent.py" --server "http://localhost:9401" --script "Get-Process | Select-Object -First 10" --interval 15 --source win_proc --index main
Can be scheduled as a Windows Scheduled Task or run directly from PowerShell 5.1/7+.
# Download cg-scripted-agent.py: ⬇ Download Python Script 
python cg-scripted-agent.py --server http://localhost:9401 --script "vmstat 1 2" --interval 60 --index cg_introspection --sourcetype host:metrics
# Standalone Native Executable CLI:
./cg-agent --server http://127.0.0.1:9401 --monitor /var/log/syslog --interval 5s --index main
Single static binary with zero runtime dependencies. Available for x86_64 Linux and Windows AMD64.
