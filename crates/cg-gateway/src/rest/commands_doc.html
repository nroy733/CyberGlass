⚡ CyberQL Command & Syntax Guide

CyberQL is CyberGlass's native streaming query language. Queries follow a pipeline execution model: initial directives evaluate through the Tantivy index, followed by zero-overhead vectorized transforms chained via pipe (|).

Root Directives & Inverted Search Directive

Clauses specified prior to the first pipe (|). These constrain the Tantivy index postings and time-range scan before records enter the streaming pipeline.

DIRECTIVE SYNTAX
index=<index_name> source="<source>" sourcetype="<type>" <field>="<val>" ["exact phrase"] [AND|OR|NOT]
DirectiveDescriptionExample
indexTarget storage index nameindex=main, index=cg_internal
sourceOrigin file, stream, or listenersource="firewall", source="/var/log/auth.log"
sourcetypeFormat classification specificationsourcetype="access_combined", sourcetype="json"
hostHostname, machine ID, or IP wildcardhost="dc01.corp", host="10.0.*"
field=valExact keyword or numerical matchingaction=blocked, status=500
*Prefix or suffix wildcard matchingsrc_ip="192.168.1.*"
Example: Firewall Denials on Port 445
⚡ Try
source="firewall" action=blocked dest_port=445 | head 50
stats Aggregation

Calculates summary aggregations across incoming events, optionally partitioned by one or more group-by fields.

COMMAND SYNTAX
| stats <function>(<field>) [as <alias>], ... [by <group_field1>, <group_field2>, ...]
FunctionDescriptionExample
countTotal event count in partitionstats count by src_ip
sum(<field>)Numeric sum of specified fieldstats sum(bytes) as total_bytes
avg(<field>)Arithmetic meanstats avg(latency_ms) by endpoint
min(<field>)Smallest numerical valuestats min(response_time)
max(<field>)Largest numerical valuestats max(bytes_out) as peak_egress
dc(<field>)Distinct count (unique cardinality)stats dc(user) as unique_users by host
values(<field>)List of deduplicated unique valuesstats values(action) by host
earliest(<field>)Earliest chronological value in groupstats earliest(_time) as first_seen
latest(<field>)Most recent chronological value in groupstats latest(status) as final_status
Example: Authentication Failures Aggregated by User
⚡ Try
source="windows_security" EventCode=4625 | stats count as failures, values(src_ip) as attacking_ips by TargetUserName | sort -failures
where Filter

Filters stream records using relational comparisons, numerical thresholds, string equality, and boolean combinations.

COMMAND SYNTAX
| where <field> <operator> <value> [AND|OR|NOT <sub-expression>]
OperatorMeaningExample
= or ==Equalitywhere action = "blocked"
!=Inequalitywhere status != 200
>, >=Greater than / Greater than or equalwhere bytes_out >= 1000000
<, <=Less than / Less than or equalwhere response_time < 50
Example: Massive Data Transfer Filter
⚡ Try
source="network" | where bytes_out > 5000000 AND action = "allowed" | table _time, src_ip, dest_ip, bytes_out
sort Ordering

Sorts records by specified fields. Prefix with - for descending (highest to lowest) or + / none for ascending.

COMMAND SYNTAX
| sort [-|+]<field1>, [-|+]<field2>, ...
Example: Highest Count First
⚡ Try
index=main | stats count by sourcetype | sort -count
dedup Deduplication

Discards subsequent events that have duplicate combinations of values for the specified fields.

COMMAND SYNTAX
| dedup <field1>, <field2>, ...
Example: Distinct IP Connections
⚡ Try
source="firewall" | dedup src_ip, dest_port | table _time, src_ip, dest_port, action
eval Computation

Creates new fields or calculates values dynamically using string, arithmetic, and logical expressions.

COMMAND SYNTAX
| eval <target_field> = <expression>
Built-in FunctionActionExample
upper(x)Converts string to uppercaseeval host_caps = upper(host)
lower(x)Converts string to lowercaseeval email_norm = lower(email)
+ - * /Mathematical calculationseval megabytes = bytes / 1048576
Example: Megabyte Bandwidth Conversion
⚡ Try
source="network" | eval total_mb = (bytes_in + bytes_out) / 1048576 | table _time, src_ip, total_mb
table & fields Projection

Projects specified fields into tabular columns or controls which fields are retained/removed in the streaming output.

COMMAND SYNTAX
| table <field1>, <field2>, ...
| fields [+|-] <field1>, <field2>, ...
Example: Clean Audit Table
⚡ Try
index=cg_audit | head 25
head & tail Limit

Restricts result set to first N or last N events in the pipeline.

COMMAND SYNTAX
| head <number>
| tail <number>
source="main" | head 20
Internal System Indexes Built-in

CyberGlass maintains isolated internal indexes for runtime logs, RBAC audit trails, and host and service telemetry. These queries support equality filters and an optional | head N stage; aggregate pipelines are not supported here.

Index NamePurposeCommon Query
cg_internalServer startup, shutdown, and runtime logsindex=cg_internal source=cyberglass.server | head 25
cg_auditRBAC security logs, user logins, token creationindex=cg_audit | head 25
cg_introspectionHost resources, ingestion, API activity, index storageindex=cg_introspection source=introspection.resources | head 25
🛡️ SOC Threat Hunting Cookbook Cookbook

1. Password Spraying & Brute Force Attack Detection

Identifies single IP addresses triggering over 10 authentication failures across multiple accounts:

Brute Force Query
⚡ Try
source="auth" action="failure" | stats count as attempts, dc(user) as unique_users by src_ip | where attempts >= 10 | sort -attempts

2. Port Scanning & Reconnaissance Activity

Detects IPs probing over 15 unique destination ports on internal hosts:

Port Recon Query
⚡ Try
source="firewall" action=blocked | stats dc(dest_port) as scanned_ports, count as total_packets by src_ip | where scanned_ports > 15 | sort -scanned_ports

3. Internal Ingestion & Error Health Analysis

Monitors CyberGlass server warnings and errors across daemon processes:

Error Monitor Query
⚡ Try
index=cg_internal severity=ERROR | head 100
